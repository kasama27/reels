# Arn Reels Companion (ส่วนเสริม Chrome)

ช่วยทำหนังสั้นหลายช็อตกับ Meta AI โดย **คุณเป็นคนกดสร้างเองทุกครั้ง** (ระดับ 2):

1. แผง “Arn Reels” บน meta.ai ดึง **ช็อตถัดไป** จากโปรเจกต์เรื่องใน Arn Reels
2. กด “วาง prompt ลงช่อง” → prompt ถูกวางในช่องพิมพ์ของ Meta AI (ไม่กดส่งให้)
3. คุณกดสร้างใน Meta AI เอง
4. พอมีวิดีโอใหม่ขึ้นในหน้า แผงจะโชว์ตัวเลือก → กด “✅ ส่งเข้าช็อต N” ไฟล์จะแนบกับช็อตนั้นใน Arn Reels
5. ครบทุกช็อตแล้วกลับไป Arn Reels → โปรเจกต์เรื่อง → ช็อต → “🎞 รวมเป็นคลิปเดียว”

## ติดตั้ง (Chrome, โหมดนักพัฒนาซอฟต์แวร์)

1. เปิดแอป Arn Reels ในเครื่องนี้ (`http://localhost:8791`)
2. Chrome → `chrome://extensions` → เปิด **โหมดนักพัฒนาซอฟต์แวร์** → **โหลดส่วนขยายที่คลายการแพ็กแล้ว** → เลือกโฟลเดอร์ `reels/extension`
3. ใน Arn Reels: ตั้งค่า → **ส่วนเสริม Chrome** → คัดลอก **รหัสจับคู่**
4. กดไอคอนส่วนเสริม (หน้าตั้งค่าเปิดขึ้น) → วางรหัส → “บันทึกและทดสอบ” ต้องขึ้น ✓
5. เปิด `meta.ai` (ล็อกอินด้วยบัญชีของคุณเอง) → แผงอยู่มุมขวาล่าง

## ความปลอดภัย

- ส่วนเสริมคุยกับ Arn Reels เฉพาะที่ `127.0.0.1`/`localhost` ด้วยรหัสจับคู่ (header `x-arn-token`) — เว็บอื่นยิงเข้ามาไม่ได้ (เซิร์ฟเวอร์เช็ก Host/Origin + รหัส)
- สร้างรหัสใหม่ได้ที่ ตั้งค่า → ส่วนเสริม Chrome → “สร้างใหม่” (รหัสเก่าใช้ไม่ได้ทันที)
- ไม่กดปุ่มใดของ Meta AI แทนคุณ ไม่อ่านแชต/ข้อมูลส่วนตัว ไม่เก็บรหัสผ่าน ไม่ฝังโค้ดจากภายนอก
- ดึงไฟล์วิดีโอได้เฉพาะโดเมนของ Meta (`meta.ai`, `facebook.com`, `fbcdn.net`, `fbsbx.com`) ตอนที่คุณกดส่งเท่านั้น

## ข้อจำกัด / สิ่งที่ยังไม่ยืนยัน

- **ยังไม่ได้ทดสอบกับหน้า meta.ai จริง** — ทดสอบกับหน้าจำลอง (ช่องพิมพ์แบบ contenteditable + วิดีโอที่โผล่ในหน้า) โดยใช้โค้ด background.js/content.js จริง หน้าเว็บของ Meta AI เปลี่ยนได้เสมอ ถ้าวาง prompt ไม่ติดหรือไม่เจอวิดีโอ ให้กด **“ตรวจหน้า”** ในแผง แล้วส่งข้อความที่ได้มา จะปรับตัวหาให้ตรงหน้าจริง
- ถ้าวางลงช่องอัตโนมัติไม่ได้ แผงจะคัดลอก prompt ให้ แล้วกด Ctrl+V เอง
- วิดีโอใหญ่เกิน ~45MB ส่งผ่านแผงไม่ได้ — ดาวน์โหลดแล้วแนบเองในหน้าโปรเจกต์
- พอร์ตของ Arn Reels ตั้งไว้ที่ 8791 ใน `manifest.json` ถ้าเปลี่ยนพอร์ต ต้องแก้ `host_permissions` ด้วย
- การใช้ซอฟต์แวร์ช่วยทำงานบนเว็บของ Meta อาจขัดเงื่อนไขการใช้งานของ Meta — ส่วนเสริมนี้ออกแบบให้คนกดสร้างเองเพื่อลดความเสี่ยง แต่ผู้ใช้เป็นผู้รับผิดชอบการใช้งานบัญชีของตัวเอง
