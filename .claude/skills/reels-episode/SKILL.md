# reels-episode — ผลิตตอนจนถึง ready

เป้าหมาย: งานตอน (`episode_jobs`) ไปถึง `ready` พร้อม `clip_id` ในคลัง **ไม่โพสต์อะไรทั้งสิ้น** — การโพสต์เป็นขั้นอื่นที่ยังไม่เปิดใช้
Arn Reels อยู่ที่ `http://localhost:8791` (ตรวจ `GET /api/status`; ดับให้ `reels/start.ps1 -NoBrowser`)

## กติกาเหล็ก
- **ถามผู้ใช้ก่อนเริ่มวาดรูปทุกตอน** (ช่วงแรกตกลงไว้ ห้ามวาดเองเมื่อแค่กดเริ่มตอน) บอกจำนวนช็อต/ตอน/ซีรีส์ แล้วรอคำตอบ
- ใช้เฉพาะเนื้อเรื่องที่อ่านจริงจากแหล่งใน `source_notes` (หรือความจำ `fanren-spoiler-sources`) ห้ามแต่ง; เรียบเรียงด้วยคำของเรา ภาพสร้างเองใหม่ทั้งหมด ไม่ลอกภาพ/บทต้นฉบับ
- ไม่พิมพ์รหัสผ่าน ไม่ผ่านหน้าล็อกอิน/CAPTCHA เอง — เจอแล้วหยุด
- ไม่ตั้งสถานะงานข้ามขั้นเอง: `images`/`render`/`ready` ขยับอัตโนมัติจากรูปและการรวมคลิป; `done` มาจากการโพสต์เท่านั้น

## ขั้นตอน
1. **เปิดงาน**: `POST /api/series/:id/jobs` (ซีรีส์ต้อง `enabled`, ไม่เกิน per_day) ได้ `job.id`/`ep_no` — ถ้า 409 บอกผู้ใช้ตามข้อความ ไม่ใช้ `force`
2. **research** (สถานะ research): อ่านบทนิยายตาม `chapter_range` ของงาน (เช่น "1-3" ได้จากการตั้งค่าซีรีส์: เริ่มที่บท + บทต่อตอน) จากแหล่งใน `source_notes` สรุปเป็น 6–12 ฉาก ถ้า `chapter_range` ว่างหรืออ่านบทนั้นไม่ได้ ให้ตั้งงานเป็น failed พร้อมเหตุผล ไม่เดาช่วงบทเอง
3. **storyboard**: เขียนสคริปต์ตามรูปแบบด้านล่าง แล้ว `POST /api/story/import` `{ text, media:"image", template:"b", series_job_id: <job.id> }` (ใส่ `"dry": true` ดูผลแยกก่อน) — ผูกโปรเจกต์ ตั้งเทมเพลต B + ป้ายตอน/การ์ดปก-จบจากซีรีส์ งานขึ้น `images` ตรวจ `warnings`
4. **ถามผู้ใช้ก่อนวาดรูป** ← จุดหยุดบังคับ
5. **images** (ได้รับอนุญาตแล้ว): ผู้สร้างรูปที่ใช้ได้จริงตอนนี้คือ Gemini ดูความจำ `gemini-image-pipeline` (ChatGPT: `chatgpt-image-pipeline`); เปิดแชตใหม่ทุกช็อต ใส่เวลาในฉาก (กลางวัน/กลางคืน) ในพรอมต์ — prompt ช็อตจาก `GET /api/story/projects/:pid` (`shots[i].prompt`, ห้ามมีขึ้นบรรทัด) → ChatGPT ในแผงเบราว์เซอร์ → ดาวน์โหลด → `PUT /api/story/shots/:id/video` (image/png) ช็อตละ ~60 วิ; เลย์เอาต์ `split` ต้องแนบรูปที่ 2 ที่ `PUT …/video2`; ช็อตที่ ChatGPT ปฏิเสธ/ไม่ตรง ลองใหม่ได้ครั้งเดียว
6. **render**: เมื่อทุกช็อตมีรูป งานขึ้น `render` เอง → เปิดหน้า Arn Reels `/?story=<pid>` แท็บ "ช็อต" กด "รวมเป็นคลิปเดียว" (เทมเพลต B, 9:16, เปิดเสียงบรรยาย) **ต้องเปิดแท็บค้างจนจบ** ระบบเรียก `clip-done` ให้เอง
7. **ready**: ตรวจ `GET /api/series/:id` ว่างานเป็น `ready` และมี `clip_id`; ดูคลิปในคลังแล้วรายงานผู้ใช้ (ความยาว, สิ่งที่ยังไม่ได้ตรวจ เช่น ยังไม่ได้ฟังเสียง)

## เมื่อล้ม
`PATCH /api/jobs/:id` `{ status:"failed", error:"<เหตุผลสั้น ๆ>" }` แล้วหยุดแจ้งผู้ใช้ ไม่ลองซ้ำเอง สาเหตุที่ต้องหยุด: เด้งล็อกอิน/CAPTCHA, แหล่งเนื้อเรื่องอ่านไม่ได้/ตอนยังไม่มี, `warnings` บอกบทพูดหาย, รูปไม่ผ่านหลังลองแล้ว, เรนเดอร์ล้ม/ความยาวผิดปกติ

## รูปแบบสคริปต์ (ต้องเรียงตามนี้)
```
"ชื่อคลิปไทยสั้น ๆ"
Create ONE vertical 9:16 storyboard illustration of <N> panels. <สรุปเรื่อง 1 ประโยคอังกฤษ>
ART STYLE: <สไตล์ภาพของเรา กรมท่า/ทอง/ส้มแดง ไม่ลอกคลิปต้นแบบ>
CONSISTENT CHARACTERS IN ALL PANELS:
1. <บทบาท>, <อายุ รูปร่าง ผม ชุด สี จุดเด่น>
PANEL 1 — <ชื่อช่อง ตัวพิมพ์ใหญ่>: <ภาพ/การกระทำ/มุมกล้อง อังกฤษ 1–3 ประโยค> Narration in Thai: "<≤90 ตัวอักษร>" Caption in Thai: "<≤60 ตัวอักษร ครอบคำเน้นด้วย {{ }}>" SFX in Thai: "<คำเสียง ≤8 ตัวอักษร หรือ "">" Meter: <1–5>
...
```

## กฎสูตร B
- ช่อง 1 = ฮุกแรงสุด ท้ายช่องแรกทิ้งคำถาม; ช่องสุดท้าย = จุดหักเหหรือฉากค้างคา
- Meter ไต่ขึ้น 1 → 5 (0 = ให้ระบบไล่เอง)
- Caption เสริม Narration ไม่ซ้ำ; เน้นคำสำคัญ 1–2 คำด้วย `{{ }}`
- SFX ใส่เฉพาะช่องที่จังหวะแรง ราวครึ่งหนึ่ง
- การ์ดปก (หลังช็อตแรก) และการ์ดจบสร้างตอนรวมคลิปเอง ไม่เขียนเป็นช่อง
- 9:16 เท่านั้น; เป้า ~60 วิ
