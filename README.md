## เริ่ม / รีสตาร์ต

```bash
start.bat            # เปิด (หรือ node server.js → http://127.0.0.1:8791)
restart.bat          # รีสตาร์ต — ดับเบิลคลิกได้ (stop.ps1 ดับเบิลคลิกไม่ได้ Windows จะเปิดใน Notepad)
```

- ต้องมี Node 22.5 ขึ้นไป ไม่ต้อง `npm install` · ตั้งค่า AI (Claude Code ที่ล็อกอินไว้ หรือคีย์ API) และเสียงพากย์ในหน้า ⚙ ตั้งค่า
- **แก้ `server.js` หรือ `lib/` → ดับเบิลคลิก `restart.bat`** (ไม่อย่างนั้นจะขึ้น "ไม่มี endpoint นี้")
- แก้ `public/` → Ctrl+F5 · แก้ `extension/` → `chrome://extensions` กด ↻ ที่ Arn Reels Companion

## คลิปสินค้า — ขั้นตอนใช้งาน

รายละเอียดเชิงเทคนิค: [docs/14-product-clips.md](docs/14-product-clips.md)

1. **หาสินค้า** — แท็บ สินค้า ขั้น ① พิมพ์คีย์เวิร์ด (หรือช่องในหน้าวันนี้) → 🔎 หาใน Shopee → เปิด affiliate.shopee.co.th และส่งคีย์เวิร์ดให้แผงค้นเอง
   - ครั้งแรก: กด "ขายดี" หรือ "คอมมิชชัน (%)" ในเว็บ แล้วค้นคำใดก็ได้ 1 ครั้ง → แผง **🛍 Arn Reels · หาสินค้า** (มุมขวาล่าง) จำวิธีค้น
   - พิมพ์คีย์เวิร์ด **ในแผง** → เลือกจำนวน / เรียง (ค่าคอมสูงสุด · ขายดีสุด) / ค่าคอมขั้นต่ำ / ราคาขั้นต่ำ → 🔎 หาสินค้า → ติ๊ก → ➕ เพิ่มเข้า Arn Reels
   - ได้: ลิงก์แอฟฟิลิเอต `s.shopee.co.th/…` ของบัญชีคุณ + รูปสินค้า + ราคา/ค่าคอม/ยอดขาย เข้าคลังสินค้า และเข้าคิวคลิปสินค้า (ไม่เก็บซ้ำ)
2. **(ไม่บังคับ)** ในหน้า 🛍 สินค้า → ✎ แก้ไข: ตั้ง "ชื่อในคลิป" สั้น ๆ / แบรนด์ / คำอ่าน · ⚙ ตั้งค่า prompt: แก้เทมเพลต V4.0, อัปโหลดรูปอ้างอิงตัวอักษร, เปิด/ปิดการใส่ข้อความไทยเอง
3. **ทำวิดีโอ** — meta.ai → แผง Arn Reels โหมด **🛍 คลิปสินค้า** → "วาง prompt + แนบรูป" → คุณกดสร้างเอง → ✅ ส่งเข้า Arn Reels (คิวเรียงเก่าสุดก่อน) · ถ้าแนบรูปไม่ติด: ⬇ ดาวน์โหลดรูป แล้วลากใส่เอง · ส่งไม่ได้: ดาวน์โหลดวิดีโอแล้วกด 📎 แนบวิดีโอ Meta AI ที่การ์ด
4. **ทำคลิปเสร็จ** — หน้าวันนี้ "ทำต่อจากตรงนี้" หรือการ์ดที่ป้าย "รอใส่ข้อความ" → 🎞 ใส่ข้อความ + ทำคลิปเสร็จ (AI เขียนแคปชัน + คอมเมนต์ให้)
5. **โพสต์** — การ์ด 📤 โพสต์ → แผงโพสต์ (เลือกช่องทาง): ดาวน์โหลด → คัดลอกแคปชัน → เปิด Meta Business Suite (แผง 🎬 Arn Reels · โพสต์ ช่วยแนบวิดีโอ/วางแคปชัน) → คอมเมนต์แรก (ลิงก์) → ✅ โพสต์แล้ว · YouTube: ชื่อคลิป + คำอธิบาย + #Shorts (Shorts กดลิงก์ไม่ได้ — ลิงก์ไว้หน้าช่อง)

```

  db.js              SQLite: clips, products, feeds (+ migration คอลัมน์)

  story.js series.js เรื่องหลายช็อต / ซีรีส์ (NARR_TONES = สไตล์เสียงร่วม)
  tts.js feeds.js pondy.js brand.js config.js claude-cli.js …
public/
  index.html app.js  หน้าหลัก: แท็บ วันนี้ / สินค้า / สร้างคลิป / คลัง / ตารางโพสต์ / ซีรีส์ + แผงโพสต์ + ตั้งค่า
  render.js          ตัวเรนเดอร์ในเบราว์เซอร์ (คลิปเร็ว, รวมช็อต, ข้อความแนะนำสินค้า)
  story.js series.*  เรื่องหลายช็อต / ซีรีส์
extension/           ส่วนเสริม Chrome (meta.ai / Flow / Gemini + affiliate.shopee.co.th + fbpost.js บน Meta Business Suite)
data/                reels.db, clip-images/ (รูปคลิป+รูปสินค้า), product-videos/ (วิดีโอดิบ Meta AI), story-videos/, product-clip.json
output/              คลิปที่เรนเดอร์แล้ว, tts/
docs/                เอกสารออกแบบ (ดูด้านล่าง)
```

## ข้อควรรู้

- **ลิงก์แอฟฟิลิเอต**: ใช้เฉพาะลิงก์ `s.shopee.co.th/…` ที่ได้จากบัญชี Shopee Affiliate ของคุณ ลิงก์สินค้าธรรมดา (เช่นที่ Pondy เก็บไว้) วางบน Facebook อาจไม่ได้ค่าคอม
- **ลิงก์ไว้คอมเมนต์แรก** ไม่ใส่ในแคปชัน (Facebook ลดการมองเห็นโพสต์ที่มีลิงก์ออกนอก)
- **ส่วนเสริมไม่กดสร้างบน Meta AI แทนคุณ** — ต้องกดเองทุกคลิป (ลดความเสี่ยงบัญชี) การใช้ซอฟต์แวร์ช่วยบนเว็บของ Meta/Shopee อาจขัดเงื่อนไขของแพลตฟอร์ม ผู้ใช้รับผิดชอบบัญชีตัวเอง
- **ฟอนต์ข้อความแนะนำสินค้า**: ติดตั้ง LINE Seed Sans TH ใน Windows จะได้ตามสเปก ไม่มีก็ใช้ฟอนต์ไทยของ Windows
