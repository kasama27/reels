# arn reels

คลังคลิป Facebook Reels: ใส่เนื้อหา/prompt → AI แตกเป็นฉาก → เรนเดอร์คลิป 9:16 ด้วย ffmpeg → AI เขียนแคปชัน+แฮชแท็ก → เก็บใน SQLite รอนำไปโพสต์

ไม่มี dependency (ไม่ต้อง `npm install`) ใช้ `node:sqlite` ในตัว Node 22.5+

## ใช้งาน

```bash
node server.js        # http://127.0.0.1:8791
```

การเรนเดอร์ทำ **ในเบราว์เซอร์** (canvas + MediaRecorder, `public/render.js`) ไม่ต้องติดตั้ง ffmpeg — ใช้ Chrome/Edge, อัดแบบเรียลไทม์ (คลัง 18 วิ = รอ 18 วิ) และต้องเปิดแท็บค้างไว้จนเสร็จ ได้ mp4 (H.264) เมื่อเบราว์เซอร์รองรับ ไม่งั้นเป็น webm ส่วน `lib/render.js` (ffmpeg) เป็นทางเลือกฝั่งเซิร์ฟเวอร์ที่ยังไม่ได้ต่อกับปุ่มในหน้าเว็บ

AI (สคริปต์/แคปชัน/อ่านรูป/prompt) เลือกได้ในหน้าตั้งค่า:
- **Claude Code ที่ล็อกอินไว้** (ค่าเริ่มต้นถ้าไม่มีคีย์): `lib/claude-cli.js` เรียก `claude -p` แบบ headless ในโฟลเดอร์ว่าง ปิดเครื่องมือทั้งหมด ใช้โควตาแผน Claude ของผู้ใช้ ไม่ต้องมีคีย์ — หาไฟล์ `claude.exe` ที่แอป Claude Desktop ติดมา (`%APPDATA%\Claude\claude-code\<ver>\…`) หรือ `claude` ใน PATH ต้องล็อกอินครั้งเดียวด้วย `claude auth login` (คำสั่งเต็มอยู่ในหน้าตั้งค่า); ช้ากว่า API เล็กน้อย; การอ่านรูปส่งผ่าน stream-json (ยังไม่ได้ทดสอบกับบัญชีที่ล็อกอินแล้ว)
- **Claude API key**: เร็วกว่า คิดเงินตามการใช้จริง

ถ้าใช้โหมด API ต้องมี:
- **คีย์ Claude API** — คัดลอก `config.example.json` เป็น `config.json` แล้วใส่ `anthropicKey` (หรือ env `ANTHROPIC_API_KEY`) ใช้เขียนสคริปต์/แคปชัน
- ฟอนต์ไทยของ Windows (Tahoma) — ตั้ง `fontFile` ถ้าอยากใช้ฟอนต์อื่น

ไม่มี auth ตั้งใจให้รันบนเครื่องตัวเองเท่านั้น (bind 127.0.0.1)

## คลังสินค้าแอฟฟิลิเอต (🛍)

ปุ่ม 🛍 สินค้า มุมขวาบน: เก็บลิงก์สินค้า (Shopee ฯลฯ ลิงก์ http/https อะไรก็ได้) พร้อมแท็ก/โน้ต/**ยอดขาย** — เพิ่มทีละชิ้น หรือวางหลายบรรทัดรูปแบบ `ชื่อ | ลิงก์ | แท็ก | โน้ต | ยอดขาย` (ลิงก์ซ้ำข้าม)
- ที่แถวคลิปกด **🛍 แนะนำสินค้า** เลือกวิธีได้ 3 แบบ: **เข้ากับคลิป (AI)** เลือกจากทั้งคลัง (ถ้าไม่มีอันที่เข้ากันจะบอกว่าไม่มี) · **ขายดี + เข้ากับคลิป** เอา 10 อันดับขายดีแล้วให้ AI เลือก · **ขายดีสุด** 3 อันดับแรกตามยอดขาย ไม่สนว่าเกี่ยวกับคลิปไหม (ไม่ใช้ AI)
- ผลลัพธ์ให้ **ชื่อลิงก์ + URL + ประโยคชวน** พร้อมปุ่มคัดลอก ไว้วางในช่อง "เพิ่มสินค้าแอฟฟิลิเอต" บน Facebook และปุ่ม "ต่อท้ายแคปชัน"
- **⚠ ค่าคอมมิชชั่น: ลิงก์ที่แอป Pondy เก็บไว้ไม่ใช่ลิงก์แอฟฟิลิเอตเสมอไป** ตรวจฐานข้อมูลบนมือถือ (19 ต.ค. 2026): เครื่องหนึ่ง 4,908 ลิงก์ทั้งหมดเป็น `https://shopee.co.th/universal-link/product/<shop>/<item>` **ไม่มีพารามิเตอร์ติดตามแอฟฟิลิเอต**; อีกเครื่อง 8,576 ลิงก์ธรรมดา + 6,355 ลิงก์สั้น `s.shopee.co.th/…` (โพสต์เก่า ส.ค.) — ช่อง `affiliateLink` ของแอปตั้งชื่อว่าแอฟฟิลิเอต แต่ค่าจริงส่วนใหญ่เป็นลิงก์สินค้าธรรมดา วางบน Facebook แล้วมีคนซื้ออาจไม่ได้ค่าคอม หน้าแนะนำสินค้าจึงแปะป้ายชนิดลิงก์ทุกการ์ด (⚠ ธรรมดา / ✓ ลิงก์สั้น) และมีตัวเลือก "เฉพาะลิงก์สั้นของ Shopee" — ลิงก์สั้นยังยืนยันไม่ได้ว่าเป็นของบัญชีผู้ใช้ ต้องแปลงเป็นลิงก์แอฟฟิลิเอตจากบัญชี Shopee Affiliate ของตัวเองก่อนวางจริง
- **ดึงจากแอป Pondy บนมือถือ** (`lib/pondy.js`): ในหน้าคลังสินค้ากด "📱 ดึงจากแอป Pondy" → ตรวจมือถือ → เลือกเครื่อง → ตั้งเงื่อนไข (ค้นชื่อ/คีย์เวิร์ด, โพสต์ภายในกี่วัน, จำนวนสูงสุด) → ดูก่อนนำเข้า/นำเข้า ระบบคัดลอกฐานข้อมูล `pipeline.db` ของแอป `com.affiliatemobile.spike` ผ่าน adb (`run-as` ใช้ได้เพราะเป็น debug build) มาอ่านจากสำเนาในโฟลเดอร์ชั่วคราว — **อ่านอย่างเดียว ไม่แก้ข้อมูลบนมือถือ** — เอาเฉพาะงานที่โพสต์แล้ว (ชื่อ + ลิงก์แอฟฟิลิเอต ไม่ซ้ำลิงก์) แท็กสินค้า = คีย์เวิร์ดที่ใช้ค้นในแอป ลิงก์ซ้ำข้าม; "🗑 ล้างที่นำเข้า" ลบเฉพาะที่นำเข้าจากมือถือ (ที่เพิ่มเองไม่ถูกลบ) ต้องมี adb (หาให้เอง หรือใส่ `adbPath` ใน config.json) ฐานข้อมูลบนมือถือ **ไม่เก็บยอดขาย** (sold) จึงไม่มีข้อมูล "ขายดี" ให้ — ใส่ยอดขายเองถ้าอยากใช้โหมดขายดี
- คลังใหญ่ (หลายพันรายการ): แสดงทีละ 50 + ค้นหา/เรียงที่เซิร์ฟเวอร์; โหมด "เข้ากับคลิป" คัดสินค้า 40 รายการที่ชื่อ/แท็กตรงกับคำในคลิปให้ AI เลือก (ไม่ส่งทั้งคลังให้ AI)
- **ค้นหา/ดึงสินค้าขายดีจาก Shopee เองไม่ได้**: Shopee ไม่มีหน้าที่ให้โปรแกรมดึงข้อมูลได้ตรง ๆ (และการดึงอัตโนมัติขัดข้อกำหนด) ยอดขายต้องใส่เอง (เช่น จากแดชบอร์ด Shopee Affiliate) — อาจมี Shopee Affiliate Open API ให้ใช้ แต่ต้องสมัครและขออนุญาต ยังไม่ได้ตรวจเงื่อนไข
- AI ถูกสั่งไม่ให้อ้างสรรพคุณ/ราคา/โปรโมชั่นที่ไม่มีในโน้ตสินค้า และควรบอกผู้ชมว่าเป็นลิงก์แอฟฟิลิเอต

## โหมดข่าว (📰)

สลับที่ปุ่มบนสุดของสตูดิโอ ใช้เรียบเรียงข่าว/โพสต์ของคนอื่นเป็นสคริปต์ + แคปชันใหม่ **ใส่ที่มาเสมอ** แล้วเก็บลงคลังรอคัดลอกไปโพสต์เอง
- **วางเอง**: วางข้อความข่าว หรือรูปแคปหน้าจอ + ใส่แหล่งที่มา → กด "เรียบเรียงข่าว" → ได้ชื่อ/สคริปต์/แคปชัน (บรรทัด "ที่มา:" ท้ายแคปชัน)/แฮชแท็ก/รายการข้อเท็จจริงที่ใช้ (ไว้ตรวจกับต้นฉบับ) → "สร้างคลิป" หรือ "💾 บันทึกร่างลงคลัง"
- **ฟีด RSS**: เพิ่มลิงก์ RSS/Atom ของเว็บข่าว (เก็บใน SQLite) → เลือกข่าวจากรายการ → "📥 ใช้เนื้อหานี้" (ดึงเนื้อบทความมาใส่ฟอร์ม) หรือ "⚡ เรียบเรียง → ลงคลัง" (ทำครบในคลิกเดียว บันทึกเป็นร่างโดยไม่เรนเดอร์)
- กติกาให้ AI: ถ้อยคำใหม่ ไม่คัดลอกประโยคเดิม คงข้อเท็จจริง/ตัวเลข/ชื่อตามต้นฉบับ ไม่แต่งเพิ่ม ไม่พาดหัวบิดเบือน — แต่ **ต้องตรวจกับต้นฉบับก่อนโพสต์เสมอ** และเนื้อหาที่แค่ปรับคำยังเสี่ยงโดน Facebook ลดการเผยแพร่ (unoriginal content) / ละเมิดลิขสิทธิ์ ควรเพิ่มมุมมองของตัวเอง
- ไม่ได้ดึงจากเพจ Facebook โดยตรง (ขัดข้อกำหนดของ Facebook / ต้อง app review) — ใช้ RSS ของเว็บข่าวหรือวางเองแทน
- ความปลอดภัย: ลิงก์ฟีด/บทความที่ชี้ไป localhost/เครือข่ายภายในถูกปฏิเสธ (กัน SSRF) รวมทุกทอด redirect

## Prompt สำหรับ Meta AI (สร้างวิดีโอเอง)

Meta ไม่มี API สร้างวิดีโอให้นักพัฒนา (ตรวจเมื่อ ต.ค. 2026) และ meta.ai ฝังใน iframe ไม่ได้ (`frame-ancestors 'self'`) เลยทำเป็นขั้นตอนคัดลอก:

1. ในสตูดิโอกด **💡 คิด prompt ให้ Meta AI** (บันทึกเป็นร่าง ไม่เรนเดอร์) หรือกด **🎬 Prompt Meta AI** ที่แถวคลิปในคลัง
2. Claude เขียน prompt อังกฤษรายฉาก (สไตล์ภาพเดียวกันทุกฉาก, vertical 9:16, ไม่มีข้อความในภาพ) แก้ไขในช่องได้ — บันทึกอัตโนมัติ
3. กด 📋 คัดลอก → **เปิด Meta AI ↗** (แท็บใหม่) → วางและสร้างวิดีโอ → ดาวน์โหลดคลิป
- ต้องมีคีย์ Claude (ตั้งค่า) ถึงให้ AI คิดให้ได้ ถ้าไม่มีก็พิมพ์ prompt เองไม่ได้ในช่อง ต้องกดให้ AI คิดก่อน
- ยังไม่ได้ทำการนำคลิปที่ได้จาก Meta AI กลับมาเป็นฉากหลัง (ทำเพิ่มทีหลังได้)

## ความยาวคลิป

ตั้งได้ที่ขั้นตอน 2 (ปุ่ม 15/30/45/60 วิ หรือกรอก 5–90 วิ; เว้นว่าง = อัตโนมัติตามความยาวสคริปต์) — AI เขียนจำนวนฉากให้พอดี (~5 วิ/ฉาก) และตัวเรนเดอร์ยืด/หดเวลาต่อฉากให้ได้ใกล้เป้า ข้อจำกัด: ฉากที่มีเสียงพากย์หดสั้นกว่าความยาวเสียงไม่ได้ และยืดได้ไม่เกิน 12 วิ/ฉาก ถ้าไม่ถึงเป้าจะมีข้อความแจ้ง

## คลังเมื่อมีคลิปเยอะ

- แสดงทีละ 24 รายการ + ปุ่ม "โหลดเพิ่ม"; ค้นหาชื่อ/แคปชัน/แฮชแท็ก; เรียงใหม่สุด/เก่าสุด (ใช้เป็นคิวโพสต์)/ชื่อ; ปุ่มกรองสถานะมีตัวเลขจำนวน
- แถวโชว์แค่หน้าปก (JPEG เล็กที่จับตอนเรนเดอร์ เก็บใน `output/thumbs/`) ไม่มี `<video>` ต่อแถว คลิกหน้าปกเพื่อเปิดตัวเล่นตัวเดียวที่ใช้ร่วมกัน; คลิปที่เรนเดอร์ก่อนมีหน้าปกจะแสดง ▶ จนกว่าจะเรนเดอร์ใหม่
- API: `GET /api/clips?status=&q=&sort=new|old|title&limit=&offset=` → `{items,total}`, `GET /api/stats`

## เสียงพากย์ + เพลง

- **เสียงพากย์ไทย** เลือกแหล่งได้ในปุ่ม ⚙ ตั้งค่า
  - *Windows ในเครื่อง* (ค่าเริ่มต้น): ฟรี ออฟไลน์ ไม่ใช้คีย์ — เสียง Microsoft Pattara ผ่าน `lib/tts.ps1` (ต้องมี Thai voice ในเครื่อง) เสียงเป็นแนวสังเคราะห์
  - *Google Cloud TTS*: เสียงธรรมชาติกว่า ต้องมีคีย์ + บัญชีเรียกเก็บเงิน (มีโควตาฟรีรายเดือน) ใส่คีย์/ชื่อเสียงในหน้าตั้งค่า แล้วกด "ทดสอบเสียง" — ชื่อเสียงที่ใช้ได้ต้องเช็กกับ Google เอง (ค่าเริ่มต้น `th-TH-Neural2-C` ยังไม่ได้ทดสอบกับคีย์จริง)
  - ไม่ได้ใส่ edge-tts เพราะเป็น endpoint ไม่เป็นทางการและเงื่อนไขการใช้เชิงพาณิชย์ไม่ชัด
- **เพลงพื้นหลัง**: เพลงสร้างสด 3 แบบ (สงบ/ลึกลับ/สนุก) เป็นต้นฉบับ ไม่มีลิขสิทธิ์ หรือวางไฟล์ของคุณ (mp3/wav/m4a/ogg) ในโฟลเดอร์ `music/` — ต้องเป็นเพลงที่คุณมีสิทธิ์ใช้เอง Facebook ตรวจลิขสิทธิ์เพลง
- คีย์ที่ใส่ผ่านหน้าตั้งค่าถูกเก็บใน `config.json` (gitignored) หน้าเว็บเห็นแค่ ••••ท้าย 4 ตัว และ `/api/*` ปฏิเสธคำขอที่ Host/Origin ไม่ใช่ localhost

## โครงสร้าง

- `server.js` — HTTP + routes (`/api/clips…`, `/media/:id.mp4` รองรับ Range)
- `lib/db.js` — SQLite (`data/reels.db`) สถานะ: draft → rendering → ready → posted / failed
- `public/render.js` — ตัวเรนเดอร์หลัก (เบราว์เซอร์): 1 บรรทัดสคริปต์ = 1 ฉาก, `หัวข้อ | รายละเอียด` = การ์ดสองชั้น; อัปโหลดผลทาง `PUT /api/clips/:id/video`
- `lib/render.js` — ตัวเรนเดอร์สำรองด้วย ffmpeg (สเปกตาม Reels API: H.264, GOP 2 วิ, AAC 48kHz, 3–90 วิ)
- `POST /api/extract` — รับรูป (data URL) → AI อ่านเนื้อหา → ชื่อ + เนื้อหา + สคริปต์ (ใช้รูปเป็นแหล่งข้อมูล ไม่ใช้เป็นภาพในคลิป)
- `lib/ai.js` — Claude API สำหรับสคริปต์และแคปชัน
- `lib/tts.js` + `lib/tts.ps1` — เสียงพากย์ (Windows / Google) แคชเป็น WAV ใน `output/tts/`
- `lib/config.js` — `config.json` + env, `cfg.save()` สำหรับหน้าตั้งค่า
- `public/` — หน้าเว็บ (อัปเดตการ์ดแบบ keyed ไม่ re-render ทั้งก้อน)
- `output/` — ไฟล์ mp4, `data/` — ฐานข้อมูล (ทั้งคู่ gitignored)

- **เพลง:** Facebook Sound Collection ใช้กับ Reels ที่โพสต์ผ่าน API ไม่ได้ ต้องมิกซ์เพลงที่ license ชัด (CC0/Pixabay) ลงไฟล์เอง และเก็บ license ไว้
- **ฉากหลังวิดีโอ:** Pexels API (ฟรี) เป็น B-roll; วิดีโอ AI (Veo 3.1 Fast/Lite ~$0.1–0.12/วิ) ใช้เป็นพื้นหลังเท่านั้น ข้อความไทยให้ ffmpeg วางทับ ไม่ให้โมเดลเรนเดอร์
