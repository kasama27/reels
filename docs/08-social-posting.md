# การโพสต์ Facebook และ YouTube (Social Posting)

**สถานะ: วางแผน ยังไม่ได้สร้างและยังไม่เคยโพสต์ทดสอบ** ทุกอย่างในไฟล์นี้เป็นข้อตกลงทิศทางที่เจ้าของเลือกไว้ ไม่ใช่สิ่งที่ทำงานอยู่ ส่วนที่ทำแล้วมีเพียงตารางบันทึกการลงและกติกาในโค้ด (05-data-model.md และ 06-api-spec.md ข้อ 1.2) ข้อจำกัดของ Facebook และ YouTube เปลี่ยนได้ ต้องตรวจหน้าเว็บจริงและเงื่อนไขปัจจุบันก่อนใช้

วิธีที่เลือก: โพสต์ผ่านหน้าเว็บด้วยเบราว์เซอร์ที่ล็อกอินไว้ ไม่ใช้ Graph API หรือ YouTube Data API เพราะเจ้าของไม่ต้องการสมัครหรือขอโทเคน แลกกับความเปราะของหน้าเว็บ

## 1. สิ่งที่ต้องเตรียม

| สิ่งที่ต้องมี | ใช้ทำอะไร | หมายเหตุ |
|---|---|---|
| เบราว์เซอร์ที่ล็อกอิน Facebook และ YouTube ค้างไว้ | โพสต์ | เจ้าของล็อกอินเอง ผู้ช่วย AI ไม่กรอกรหัสผ่าน (ดูประเด็นที่ 12 ว่าใช้เบราว์เซอร์ตัวไหน) |
| ชื่อเพจ Facebook | เลือกเพจที่จะลง | ตั้งไว้ในซีรีส์: "Liem facebook" ตามที่เจ้าของพิมพ์ ยังไม่ตรวจกับชื่อจริง (ประเด็นที่ 13) |
| ชื่อช่อง YouTube | เลือกช่องที่จะลง | ตั้งไว้ในซีรีส์: "เหลี่ยม youtube" ตามที่เจ้าของพิมพ์ ยังไม่ตรวจ (ประเด็นที่ 13) |
| รหัสเพจ Facebook | ยืนยันว่าเปิดถูกเพจ | เจ้าของให้ลิงก์ `profile.php?id=61574650544656` ยังไม่ได้เก็บในระบบ **(รอยืนยัน)** ประเด็นที่ 13 |
| คลิปที่พร้อมโพสต์ | ไฟล์ที่อัปโหลด | งานตอนต้องเป็น "พร้อมโพสต์" มีเลขคลิป |
| แคปชันและแฮชแท็กของคลิป | ข้อความโพสต์ | มาจากคลิป (ระบบเขียนให้ตอนรวมคลิป) |

## 2. สิ่งที่ผู้ใช้เห็น

- หน้าซีรีส์แสดงสถานะการลงของแต่ละช่องทางและลิงก์โพสต์ เมื่อมี
- เมื่อโพสต์ถูกหยุด หน้าซีรีส์แสดงเหตุผล เจ้าของต้องแก้แล้วสั่งต่อ
- ไม่มีปุ่มโพสต์ในหน้าเว็บ ไม่มีปุ่มบันทึก "ลงแล้ว" ด้วยมือสำหรับซีรีส์ เพื่อไม่ให้ข้ามขั้นยืนยันป้ายเนื้อหา AI

## 3. ลำดับการทำงานระหว่างระบบกับ Facebook และ YouTube

| เหตุการณ์ | เงื่อนไข | สิ่งที่ระบบทำ |
|---|---|---|
| เริ่มลง | ตอนเป็นพร้อมโพสต์ ช่องทางนั้นถูกเลือก ยังไม่มีรายการลงของช่องทางนั้น | สร้างรายการลงสถานะ "รอลง" แล้วเปลี่ยนเป็น "กำลังลง" |
| เปิดเพจหรือช่อง | ล็อกอินอยู่ | เปิดหน้าอัปโหลดของเพจ/ช่องตามชื่อที่ตั้งไว้ ตรวจว่าชื่อตรงก่อนไปต่อ ไม่ตรง → "ถูกหยุด" |
| อัปโหลดและใส่ข้อความ | ไฟล์ผ่านการอัปโหลด | ใส่ไฟล์คลิป แคปชัน แฮชแท็ก |
| ติ๊กป้ายเนื้อหา AI | Facebook: ตัวเลือก AI-generated; YouTube: ตัวเลือกเนื้อหาที่ดัดแปลงหรือสร้างขึ้น | ติ๊กแล้วอ่านค่ากลับมายืนยัน ถ้าหาตัวเลือกไม่เจอหรือยืนยันไม่ได้ → "ถูกหยุด" ไม่โพสต์ |
| กดโพสต์ | ยืนยันป้ายแล้ว | กดโพสต์ จดลิงก์โพสต์ |
| บันทึกผล | มีลิงก์ https | ตั้ง "ลงแล้ว" พร้อมค่ายืนยันป้ายและลิงก์ (ระบบปฏิเสธถ้าขาดอย่างใดอย่างหนึ่ง) |
| ครบทุกช่องทาง | ทุกช่องทางที่เลือกลงแล้ว | งานตอนเป็น "ลงครบแล้ว" เอง |
| ช่องทางที่สอง | ช่องทางแรกลงแล้ว | เว้นช่วง (ข้อเสนอ 45 นาที รอยืนยัน ประเด็นที่ 12) แล้วทำซ้ำ |

หลักการตัดสินใจ: เจ้าของตัดสินใจแล้วว่า **โพสต์ทันทีเมื่อคลิปพร้อม ไม่ต้องรอเจ้าของอนุมัติ** (ประเด็นที่ 8) จึงไม่มีขั้นอนุมัติ ความปลอดภัยทั้งหมดอยู่ที่กติกาหยุด

## 4. ข้อจำกัดที่ต้องรู้

| เรื่อง | ข้อจำกัด | ผลต่อระบบ |
|---|---|---|
| ล็อกอินและ CAPTCHA | หน้าเว็บอาจเด้งขอล็อกอินหรือ CAPTCHA | หยุด ไม่ผ่านเอง ไม่กรอกรหัสผ่าน |
| หน้าเว็บเปลี่ยน | ตำแหน่งปุ่มและตัวเลือกเปลี่ยนได้โดยไม่แจ้ง | ต้องหยุดแทนที่จะเดา ต้องจดตำแหน่งตัวเลือกป้าย AI หลังทดสอบจริง |
| บัญชีถูกจำกัด | Facebook และ YouTube อาจจำกัดบัญชีที่กดอัตโนมัติ หรือเนื้อหาผลิตซ้ำจำนวนมาก (YouTube มีนโยบายเรื่องนี้) | เป็นความเสี่ยงของเจ้าของ (ประเด็นที่ 15) |
| ขนาดและความยาวคลิป | ไม่ได้ตรวจเงื่อนไขปัจจุบันของแต่ละแพลตฟอร์ม | ต้องตรวจก่อนเปิดงานจริง (plans/poc-plan.md) |
| ต้องมีเครื่องเปิดและเบราว์เซอร์เปิด | งานรอบนั้นล้มถ้าเครื่องหลับหรือเบราว์เซอร์ปิด | ประเด็นที่ 12 |
| ไม่มีผู้อนุมัติ | โพสต์ทันที เสียงที่ผู้ใช้ยังไม่ได้ฟังก็โพสต์ได้ | ประเด็นที่ 8 และ 16 เจ้าของรับความเสี่ยง |

## 5. ค่าใช้จ่าย

ไม่มีค่า API เพราะไม่ใช้ API ค่าใช้จ่ายที่เหลือคือเวลาและโควตาของบัญชี AI

## 6. รายการทดสอบการเชื่อมต่อ

ก่อนเปิดงานรายวัน ต้องทดสอบโพสต์คลิปทดสอบ 1 คลิปต่อช่องทาง โดยเจ้าของอนุมัติก่อนกดโพสต์ทุกครั้ง (plans/poc-plan.md)

| # | ทดสอบ | ผลที่ต้องได้ |
|---|---|---|
| 1 | เปิดหน้าเพจ/ช่องด้วยชื่อที่ตั้งไว้ | ตรวจชื่อได้ตรง ไม่ตรงหยุด |
| 2 | อัปโหลดคลิปทดสอบ | ไฟล์ขึ้นครบ ไม่ล้ม |
| 3 | ติ๊กป้ายเนื้อหา AI และอ่านค่ากลับ | อ่านได้ว่าติ๊กแล้ว |
| 4 | จำลองหาตัวเลือกป้ายไม่เจอ | ไม่โพสต์ รายการลงเป็น "ถูกหยุด" |
| 5 | จำลองหน้าล็อกอิน | หยุดพร้อมเหตุผล |
| 6 | โพสต์สำเร็จแล้วบันทึกลิงก์ | รายการลงเป็น "ลงแล้ว" มีลิงก์ ค่ายืนยันป้ายเป็นจริง |
| 7 | สั่งโพสต์ตอนเดิมซ้ำ | ระบบปฏิเสธ |
