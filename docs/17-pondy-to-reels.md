## 2. สั่งสร้างคลิป (meta.ai → `extension/content.js` โหมด 🛍 คลิปสินค้า)

| กับดักของ Pondy (16-pondy-clip.md §6) | ใน Reels | สถานะ |
|---|---|---|
| 1. แชทเก่า → ได้คลิปผิดสินค้า: เปิดแชทใหม่ทุกชิ้น ตรวจว่าว่าง | ก่อนวาง ตรวจสื่อเก่าในแชท ถ้ามี → ไม่วาง ขึ้นปุ่ม **🆕 แชทใหม่แล้ววาง** (โหลดหน้าแรก Meta AI ใหม่ แล้ววางให้เอง) หรือ "วางในแชทนี้" | ✅ รอบ 7 |
| 2. ข้อความไปลงช่องผิด → อ่านกลับ 30 ตัวแรก ไม่ขึ้นลองอีกรอบ (แทนที่) | `promptHas()` อ่านกลับ 30 ตัวแรก + ลองซ้ำ 1 รอบ · ไม่ได้ → คัดลอกให้ Ctrl+V | ✅ รอบ 7 |
| 3. URI รูปซ้ำ → เว็บใช้รูป cache ของสินค้าก่อน | ชื่อไฟล์ `product-<clip>-<เวลา>.png` ใหม่ทุกครั้ง | ✅ รอบ 7 |
| 4. รูปค้างในช่องแนบ / รูปหายหลังวางข้อความ | รอ thumbnail ขึ้น ≤8 วิ แล้วตรวจซ้ำหลังวางข้อความ · หาย → เตือนให้ลากใส่ใหม่ | ✅ รอบ 7 (ยังไม่ลบรูปค้างให้ — เปิดแชทใหม่แทน) |
| 5. ไทล์โผล่ก่อนเรนเดอร์เสร็จ | รับเฉพาะ `<video>` ที่ `readyState≥1` และส่งได้เมื่อยาว 3–60 วิ · เตือนถ้าไม่ใช่แนวตั้ง | ✅ รอบ 7 |
| 6. ตอบเป็นข้อความ/รูปแทนวิดีโอ/อัปโหลดค้าง | แผงเฝ้าหลังวาง: ข้อความปฏิเสธ (ขออภัย/limit/…) → เตือนโควต้าเต็ม รอ ~10 นาที · ได้รูปนิ่ง → เตือน · เกิน 8 นาที → เตือน | ✅ รอบ 7 |

## 3. ถ้าจะทำต่อ (ลำดับแนะนำ)
1. ฝั่ง server: ตรวจวิดีโอที่รับเข้าด้วย ffprobe (ยาว/แนวตั้ง) แล้วตีกลับพร้อมเหตุผล
2. แผงหาสินค้า: ตรวจหลุดล็อกอิน + หยุดเมื่อพลาด 3 ครั้งติด
3. รายการแทนคำต้องห้ามในชื่อสินค้าที่ใส่ prompt (ดู 16-pondy-clip.md §3 และกับดักข้อ 18–19)
