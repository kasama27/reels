# การสร้างรูปผ่านเว็บภายนอก (Image Generation)

ระบบไม่เรียก API สร้างรูปของผู้ให้บริการใดโดยตรง ใช้เว็บของผู้สร้างรูปผ่านเบราว์เซอร์ที่ล็อกอินด้วยบัญชีของเจ้าของ ผู้ช่วย AI เป็นผู้พิมพ์พรอมต์และเก็บรูป เนื้อหาในไฟล์นี้มาจากการทดลองจริงเมื่อ 28 ต.ค. 2026 กับตอนทดลอง EP.1 (6 ช็อต) ข้อจำกัดของบริการภายนอกเปลี่ยนได้ ให้ตรวจค่าปัจจุบันก่อนตัดสินใจ

## 1. สิ่งที่ต้องเตรียม

| สิ่งที่ต้องมี | ใช้ทำอะไร | หมายเหตุ |
|---|---|---|
| บัญชีผู้สร้างรูปที่ล็อกอินค้างในเบราว์เซอร์ | วาดรูปตามพรอมต์ | ผู้สร้างรูปที่ทดลองแล้ว: Gemini (gemini.google.com) ใช้ได้จริง, ChatGPT และ Gemini แบบไม่ล็อกอินสร้างรูปไม่ได้ เจ้าของล็อกอินเอง ผู้ช่วย AI ไม่ล็อกอินหรือสมัครให้ |
| เบราว์เซอร์ที่ผู้ช่วย AI ควบคุมได้ | เปิดเว็บ พิมพ์ กดส่ง อ่านรูป | แผงเบราว์เซอร์ในแอป Claude หรือ Chrome (ดูประเด็นที่ 12) สองตัวนี้เป็นเบราว์เซอร์แยกกัน ล็อกอินไม่ใช้ร่วมกัน |
| พรอมต์ต่อช็อต | ข้อความสั่งวาด | มาจากโปรเจกต์ (06-api-spec.md ข้อ 2) ตัดคำบรรยายภาษาไทยออกก่อนส่ง กันภาพมีตัวอักษร |
| โฟลเดอร์ดาวน์โหลดของผู้ใช้ | ทางผ่านของไฟล์รูป | ไฟล์อาจค้างเป็นไฟล์ชั่วคราว ต้องตรวจก่อนใช้ |

## 2. สิ่งที่ผู้ใช้เห็น

- เจ้าของเห็นหน้าเว็บผู้สร้างรูปในแผงเบราว์เซอร์ และเห็นรูปขึ้นในช่องแชต
- หน้าเรื่องใน Arn Reels แสดงรูปที่แนบในแต่ละช็อต และตัวนับ "รูป x/y" ในหน้าซีรีส์
- ถ้าไฟล์ดาวน์โหลดต้องกดบันทึก เจ้าของเห็นหน้าต่างถามบันทึกไฟล์ (ปัญหาที่เจ้าของแจ้ง ดูประเด็นที่ 11)

## 3. ลำดับการทำงานระหว่างระบบกับผู้สร้างรูป

| เหตุการณ์ | เงื่อนไข | สิ่งที่ระบบทำ |
|---|---|---|
| เริ่มช็อต | เปิดแชตใหม่ทุกช็อต | เปิดหน้าผู้สร้างรูป คลิกช่องพิมพ์ ใส่ "Generate one vertical 9:16 image: ..." พรอมต์ที่มีคำอธิบายตัวละครเต็มทุกครั้ง แล้วกดส่ง |
| รอผลลัพธ์ | ประมาณ 1 ถึง 2 นาทีต่อช็อต | อ่านหน้าเว็บเป็นระยะจนเห็นรูปขนาดใหญ่ในแชต |
| ได้รูป | รูปเป็นภาพในหน้า (blob) | วาดรูปลงผืนผ้าใบแล้วสั่งดาวน์โหลดเป็น PNG ลงโฟลเดอร์ดาวน์โหลด |
| ตรวจไฟล์ | ลายเซ็นเป็น PNG จริง ขนาดตรงกับที่ดาวน์โหลด | ถ้าไฟล์ค้างเป็นไฟล์ชั่วคราว ใช้ไฟล์นั้นได้เมื่อผ่านการตรวจลายเซ็น |
| อัปโหลด | ช็อตมีเลขแล้ว | ส่ง PNG ไปที่เส้นทางแนบรูปของช็อต (06-api-spec.md ข้อ 2.3) แล้วงานตอนขยับตามจำนวนรูป |
| ตรวจภาพ | ผู้ช่วย AI เปิดดูไฟล์ | ตรวจว่าไม่มีตัวอักษรในภาพ ตัวละครหน้าตาคงที่ ถ้าไม่ผ่านลองใหม่ได้ครั้งเดียว |
| เจอหน้าล็อกอินหรือขอให้สมัคร | ผู้สร้างรูปไม่ได้ล็อกอิน | หยุดทันที แจ้งเจ้าของ ไม่ล็อกอินให้ |

## 4. ข้อจำกัดที่ต้องรู้

| เรื่อง | ข้อจำกัด | ผลต่อระบบ |
|---|---|---|
| การล็อกอินหลุด | เกิดจริงกับ ChatGPT และ Gemini ในแผงเบราว์เซอร์ระหว่างวันที่ทดลอง | งานอัตโนมัติล้มที่ขั้นรูป ต้องมีวิธีตรวจและแจ้ง (ประเด็นที่ 12 และ 17) |
| แชตค้างหลังสร้างรูปแรก | แชตเดิมค้างสถานะ "กำลังสร้างรูป" ส่งข้อความต่อไม่ได้ | ต้องเปิดแชตใหม่ทุกช็อต ทำให้ตัวละครคงที่ได้ด้วยคำอธิบายในพรอมต์เท่านั้น ไม่ได้ด้วยความจำของแชต |
| ขนาดรูป | ประมาณ 572 × 1024 พิกเซล เล็กกว่าคลิป 1080 × 1920 | ภาพนุ่มลงเล็กน้อยตอนขยาย (ค่าที่เห็นในการทดลอง ผู้ให้บริการอาจเปลี่ยน) |
| เวลา | ประมาณ 1 ถึง 2 นาทีต่อรูป | ตอน 6 ช็อตใช้ประมาณ 6 ถึง 12 นาที ตอน 10 ช็อตมากกว่านั้น กระทบเวลาเริ่มงานรายวัน |
| ฉากกลางวันกลางคืน | ผู้สร้างรูปเลือกเวลาในฉากเองถ้าพรอมต์ไม่ระบุ | ในการทดลอง ช็อต 3 ถึง 5 เป็นกลางคืนทั้งที่เนื้อเรื่องเป็นกลางวัน ต้องใส่เวลาในพรอมต์ |
| ไฟล์ดาวน์โหลด | เบราว์เซอร์ถามบันทึก หรือไฟล์ค้างเป็นไฟล์ชั่วคราว | ต้องมีทางส่งตรง (ประเด็นที่ 11) |
| ส่งตรงเข้าแอป | เว็บภายนอกส่งเข้า localhost ไม่ได้ เพราะเซิร์ฟเวอร์ตรวจ Origin | ตั้งใจให้เป็นเช่นนั้น เพื่อกันเว็บอื่นเขียนลงแอป |
| ส่วนเสริม Chrome | รองรับ meta.ai, Google Flow และ Gemini (รุ่น 0.3.0 ทดสอบส่งรูปเข้าช็อตด้วยมือแล้ว โหมดอัตโนมัติยังไม่ได้ทดสอบ) ไม่รองรับ ChatGPT | เป็นทางที่เจ้าของเลือก (ประเด็นที่ 11) ส่งรูปเข้าช็อตตรงโดยไม่ผ่านโฟลเดอร์ดาวน์โหลด |
| รายการผู้สร้างรูปในระบบ | มี gemini แล้ว (เฟส 1) ใช้ได้กับแบบงานภาพนิ่งเท่านั้น | โปรเจกต์ระบุ Gemini ได้ |
| ลิขสิทธิ์และนโยบาย | ภาพสร้างเองทุกช็อต ห้ามใช้ภาพต้นฉบับ แต่เนื้อเรื่องอ้างอิงงานของคนอื่น | ประเด็นที่ 15 |

## 5. ค่าใช้จ่าย

- ทางเว็บ (ที่ใช้อยู่): ไม่มีค่าใช้จ่ายที่เห็นชัดกับบัญชีที่ใช้ โควตาต่อวันของบัญชีไม่ทราบ
- ทาง Gemini API (ทดสอบแล้ว 28 ต.ค. 2026 ยังไม่ได้ต่อเข้าแอป): คีย์ของแอปสร้างรูปได้ รูป 9:16 ขนาด 768 × 1376 ใช้เวลา 6 ถึง 22 วินาทีต่อรูป ราคาตามหน้าราคาของ Google ประมาณ $0.034 ต่อรูปสำหรับรุ่นที่ทดสอบ ไม่มีโควตาฟรี ต้องตรวจราคาและชื่อรุ่นปัจจุบันก่อนใช้ เพราะรุ่นเปลี่ยนเร็ว (รุ่นเก่า gemini-2.5-flash-image ประกาศปิดเมื่อ 2 ต.ค. 2026) ดูประเด็นที่ 11 และ 12

## 6. รายการทดสอบการเชื่อมต่อ

| # | ทดสอบ | ผลที่ต้องได้ |
|---|---|---|
| 1 | เปิดผู้สร้างรูปแล้วตรวจว่าล็อกอินอยู่ (ไม่มีปุ่มลงชื่อเข้าใช้) | ผ่านก่อนเริ่มทุกตอน ไม่ผ่านให้หยุด |
| 2 | ส่งพรอมต์ 1 ช็อตในแชตใหม่ | ได้รูป 9:16 ภายใน 3 นาที ไม่มีตัวอักษรในภาพ |
| 3 | ดาวน์โหลดแล้วอัปโหลดเข้าช็อต | ช็อตแสดงรูป ตัวนับรูปในหน้าซีรีส์เพิ่ม |
| 4 | อัปโหลดรูปครบทุกช็อต | งานตอนเปลี่ยนเป็นรวมคลิปเอง |
| 5 | เอารูปหนึ่งช็อตออก | งานตอนกลับเป็นทำรูป |
| 6 | ล็อกอินหลุดกลางทาง | งานหยุดพร้อมเหตุผล ไม่มีรูปครึ่งทางค้างผิดช็อต |
