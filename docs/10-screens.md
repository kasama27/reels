# รายการหน้าจอ (Screen List)

ข้อมูลถอดจากไฟล์หน้าเว็บ `public/index.html`, `app.js`, `story.js`, `series.html` เมื่อ 28 ต.ค. 2026 ชื่อหน้าจอตั้งตามหัวข้อที่ผู้ใช้เห็นบนหน้าจอ ระบบมีผู้ใช้กลุ่มเดียว (เจ้าของระบบ) จึงไม่มีตารางสิทธิ์รายเมนู

คอลัมน์ "ความสำคัญ": ต้องมี = ระบบใช้งานเส้นทางหลักไม่ได้ถ้าไม่มี, ทำต่อ = ยังต้องมีก่อนเปิดงานอัตโนมัติเต็มรูป, เฟสหลัง = ทำหรือจัดใหม่ทีหลัง

ค่าในคอลัมน์ "ความสำคัญ" ของหน้าที่ทำแล้ว หมายถึงความสำคัญต่อเป้าหมายงานอัตโนมัติ ไม่ใช่ลำดับการสร้าง (สร้างเสร็จแล้ว)
