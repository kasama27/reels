# รายการ API (API Specification)

ข้อมูลถอดจากโค้ด `server.js` เมื่อ 28 ต.ค. 2026 เส้นทางที่ไม่ได้อธิบายละเอียดในตาราง ดูกติกาตรวจข้อมูลได้ที่ฟังก์ชันตรวจของเส้นทางนั้นในโค้ด

Base URL: `http://127.0.0.1:8791` (พอร์ตดู 05-data-model.md ข้อ 3) ไม่มีเลขรุ่นใน path
รูปแบบ: REST + JSON (ไฟล์วิดีโอและรูปส่งแบบไบนารีด้วย PUT)
ไม่มีการยืนยันตัวตนสำหรับหน้าเว็บและผู้ช่วย AI (เครื่องเดียว) ส่วนเส้นทาง `/ext/` ต้องมีรหัสจับคู่ (ข้อ 8)

รหัสสถานะที่ใช้: 200 สำเร็จ, 400 ข้อมูลไม่ถูกต้อง, 401 รหัสจับคู่ผิด, 403 Host หรือ Origin ไม่อนุญาต, 404 ไม่พบ, 409 ขัดกับกติกาหรือสถานะปัจจุบัน, 413 ไฟล์ใหญ่เกิน, 415 ชนิดไฟล์ไม่รองรับ, 500 ข้อผิดพลาดภายใน, 502 บริการภายนอกผิดพลาด

รูปแบบ Error ทุกจุด

```json
{ "error": "ข้อความภาษาไทยบอกสาเหตุ" }
```

## 1. ซีรีส์ งานตอน และการลง

ผู้เรียก: เจ้าของ (หน้าซีรีส์) และผู้ช่วย AI ทุกเส้นทาง กติกาทั้งหมดบังคับที่เซิร์ฟเวอร์ ไม่ใช่ที่หน้าเว็บ

### 1.1 ซีรีส์
| Method | Path | คำอธิบาย |
|---|---|---|
| GET | /api/series | รายการซีรีส์ทั้งหมด |
| POST | /api/series | สร้างซีรีส์ ต้องมี title ตั้ง channels channel_ids chapter_start chapters_per_ep platforms post_time per_day next_ep visual tpl source_notes ได้ ปฏิเสธ 400 ถ้าเปิดป้าย AI เป็นปิด ซีรีส์ใหม่ `enabled` เป็น false เสมอ |
| GET | /api/series/:id | ซีรีส์พร้อมรายการตอนและการลงของแต่ละตอน และความคืบหน้ารูป (progress) |
| PATCH | /api/series/:id | แก้ฟิลด์ที่ส่งมา channels แทนที่ทั้งก้อน ปฏิเสธ 400 ถ้า ai_label ไม่ใช่ true |
| DELETE | /api/series/:id | ลบซีรีส์ พร้อมงานและการลง (ไม่ลบโปรเจกต์และคลิป) |

### 1.2 งานตอน
| Method | Path | คำอธิบาย |
|---|---|---|
| POST | /api/series/:id/jobs | เริ่มตอนถัดไป คำนวณ chapter_range ของตอน ปฏิเสธ 409 ถ้าซีรีส์ปิดอยู่ (ยกเว้นส่ง force เป็น true) ครบตอนต่อวันแล้ว หรือเลขตอนซ้ำ ไม่เกิดผลซ้ำเมื่อเรียกซ้ำ (ครั้งที่สองถูกปฏิเสธ) |
| PATCH | /api/jobs/:id | แก้ status error project_id clip_id platforms chapter_range (เลขบท เช่น 3 หรือ 3-5 บทเริ่มไม่เกินบทสุดท้าย) ปฏิเสธ 400 ถ้าตั้ง done เอง หรือ ready โดยไม่มี clip_id ปฏิเสธ 409 ถ้าตอนเป็น done แล้ว หรือเอาช่องทางที่เริ่มลงแล้วออก ส่ง platforms เป็น null เพื่อใช้ตามซีรีส์ |
| DELETE | /api/jobs/:id | ลบงานตอนและการลง (ไม่ลบโปรเจกต์และคลิป) |
| POST | /api/jobs/:id/publications | สร้างรายการลงตาม platform ปฏิเสธ 409 ถ้าตอนยังไม่ ready หรือมีรายการนั้นแล้ว ปฏิเสธ 400 ถ้าช่องทางไม่ได้เลือกไว้ |
| PATCH | /api/publications/:id | แก้ status url ai_label_verified error ปฏิเสธ 409 ถ้าตั้ง posted โดยยังไม่ยืนยันป้าย AI และ 400 ถ้าไม่มี url https และปฏิเสธ 409 ถ้ารายการ posted แล้ว เมื่อโพสต์ครบช่องทางที่เลือก ตอนเป็น done เอง |

## 10. รหัส Error ที่ใช้บ่อย

ระบบไม่มีรหัส error แยก มีเฉพาะรหัส HTTP และข้อความในฟิลด์ error ข้อความที่ผู้ช่วย AI ต้องรู้ความหมาย:

| ข้อความ (ตัวอย่าง) | HTTP | ความหมาย |
|---|---|---|
| ซีรีส์ยังปิดอยู่ | 409 | เริ่มตอนไม่ได้จนกว่าจะเปิดซีรีส์ |
| ครบ N ตอนของวันนี้แล้ว | 409 | ถึงเพดานตอนต่อวัน |
| ตอน N มีงานอยู่แล้ว | 409 | เลขตอนซ้ำ |
| ยังไม่ได้ยืนยันป้ายเนื้อหา AI | 409 | บันทึกว่าลงแล้วไม่ได้ |
| ต้องรูปครบก่อนจึงจะเป็น ready | 409 | รวมคลิปเสร็จตอนงานไม่ได้อยู่ขั้นรวมคลิป |
| ป้ายเนื้อหา AI ต้องเปิดเสมอ | 400 | พยายามปิดป้าย |
| ไม่พบหัวฉาก | 400 | สคริปต์นำเข้าผิดรูปแบบ |
| ไฟล์ไม่ใช่รูปจริง | 400 | ลายเซ็นไฟล์ไม่ตรง |
