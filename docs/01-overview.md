## Arn Reels

## 1. ที่มาและวัตถุประสงค์

Arn Reels เป็นแอปที่รันในเครื่องของเจ้าของ (ที่ `http://127.0.0.1:8791`) ใช้ทำคลิปแนวตั้ง 9:16 เก็บไว้ในคลัง เขียนแคปชัน และเตรียมโพสต์ลงเพจ Facebook เริ่มจากคลิปข้อความสั้น ๆ แล้วขยายเป็นโปรเจกต์เรื่องหลายช็อต และตอนนี้กำลังต่อยอดเป็นซีรีส์รายวันที่ให้ระบบผลิตตอนและโพสต์เองตามเวลา

**เป้าหมาย:** ให้เจ้าของระบบคนเดียวผลิตและโพสต์คลิปซีรีส์สปอยทุกวันบนหลายช่องทาง โดยลงมือเองให้น้อยที่สุด

**ผลลัพธ์ที่ระบบต้องทำได้เมื่อเปิดใช้งานเต็มรูป**
- สร้างคลิปจากข้อความ ข่าว หรือสินค้า แล้วเก็บไว้ในคลังพร้อมแคปชัน
- สร้างโปรเจกต์เรื่องจากสคริปต์หรือหัวข้อ ทำรูปทีละช็อต และรวมเป็นคลิปเดียวด้วยเทมเพลตสปอยล์
- ตั้งซีรีส์หนึ่งเรื่อง แล้วให้ระบบผลิตตอนถัดไปทุกวันได้เอง ตั้งแต่เนื้อเรื่องจนถึงคลิปพร้อมโพสต์
- โพสต์คลิปลง Facebook และ YouTube พร้อมติ๊กป้ายเนื้อหา AI และยืนยันก่อนโพสต์ทุกครั้ง **(วางแผน)**

## 2. ขอบเขตระบบ

**อยู่ในขอบเขต**
- คลังคลิป คลังข่าว (RSS) และคลังสินค้าแอฟฟิลิเอต
- โปรเจกต์เรื่อง: ตัวละคร ช็อต พรอมต์ รูป เทมเพลตและเสียง
- ซีรีส์ งานผลิตตอน และบันทึกการลงต่อแพลตฟอร์ม
- โพสต์อัตโนมัติผ่านเบราว์เซอร์ **(วางแผน)**
- ตัวตั้งเวลารายวัน **(วางแผน)**

**นอกขอบเขต**
- ระบบหลายผู้ใช้และรหัสผ่าน: ตั้งใจให้ใช้บนเครื่องเดียวของเจ้าของ (ดู 11-security.md)
- การโพสต์ผ่าน Graph API หรือ YouTube Data API: เลือกใช้เบราว์เซอร์ที่ล็อกอินไว้แทน เพื่อไม่ต้องขอสิทธิ์หรือโทเคน
- โครงการ `pondy-console` และ `pondy-fleet-web` ในโฟลเดอร์ข้างเคียง เป็นระบบแยก มีเพียงการนำเข้ารายการสินค้าจากมือถือ (Flow 4) — แหล่งสินค้าหลักตอนนี้คือแผงหาสินค้าบน affiliate.shopee.co.th (14-product-clips.md)

## 3. ผู้ใช้งานระบบ

| กลุ่ม | ช่องทาง | บทบาท |
|---|---|---|
| เจ้าของระบบ | หน้าเว็บ Arn Reels (หน้าหลัก หน้าเรื่อง หน้าซีรีส์) | ตั้งค่า สั่งงาน ตรวจผล เป็นผู้ตัดสินใจทุกเรื่อง |
| ผู้ช่วย AI (Claude) | เครื่องมือในแอป Claude Code และเบราว์เซอร์ | ทำงานตามขั้นตอนผลิตตอนและโพสต์แทนเจ้าของเมื่อสั่งหรือเมื่อถึงเวลา |
| งานตั้งเวลา | Claude scheduled task **(วางแผน)** | เริ่มผลิตและโพสต์ตามรอบวัน |

ไม่มีผู้ใช้กลุ่มอื่น ระบบไม่มีบัญชีผู้ใช้

## 4. ข้อมูลหลักที่ทุกคนต้องรู้

ระบบมี 3 ชั้นงาน เรียงจากเก่าไปใหม่ ใช้ฐานข้อมูลและหน้าเว็บร่วมกัน

| ชั้น | ทำอะไร | ผลลัพธ์ |
|---|---|---|
| คลิปเร็ว | ข้อความหรือข่าวหรือสินค้า → สคริปต์ → เรนเดอร์ | คลิปหนึ่งคลิปในคลัง |
| โปรเจกต์เรื่อง | เรื่องหลายช็อต → รูปต่อช็อต → รวมเป็นคลิป | คลิปหนึ่งคลิป (ชนิด "เรื่อง") |
| ซีรีส์ | ซีรีส์ → ตอน → การลงต่อแพลตฟอร์ม | ตอนที่พร้อมโพสต์ และบันทึกการลง |

ช่องทางที่ลงได้: **Facebook** และ **YouTube**

## 5. การแบ่งทีมพัฒนา

ยังไม่ได้กำหนดทีม ผู้พัฒนาปัจจุบันคือเจ้าของระบบร่วมกับผู้ช่วย AI ตำแหน่งที่ควรมีเมื่อขยาย: ผู้พัฒนาระบบหลัก (เซิร์ฟเวอร์และฐานข้อมูล) ผู้พัฒนาหน้าเว็บและตัวเรนเดอร์ และผู้ดูแลงานอัตโนมัติ (ล็อกอินและตั้งเวลา) ยังไม่ได้กำหนดว่าใครรับตำแหน่งใด

## 6. ข้อจำกัดและเงื่อนไข

- ต้องใช้ Chrome หรือ Edge: เรนเดอร์คลิปในเบราว์เซอร์ ต้องเปิดหน้าค้างไว้จนเรนเดอร์จบ และเรนเดอร์ใช้เวลาเท่าความยาวคลิป
- ต้องใช้ Node 22.5 ขึ้นไป (ใช้ฐานข้อมูล SQLite ในตัว) ไม่มีไลบรารีภายนอก
- การสร้างรูปพึ่งเว็บภายนอก (Gemini, ChatGPT, Google Flow) ที่ล็อกอินค้างไว้ การล็อกอินหลุดได้ (ดู 07-image-generation.md)
- ไม่มีรหัสผ่าน: ให้รันบนเครื่องของเจ้าของเท่านั้น
- ป้ายเนื้อหา AI บังคับทุกโพสต์ และปิดไม่ได้ในระบบ
- ภาพทุกช็อตต้องสร้างเอง ห้ามใช้ภาพจากอนิเมะหรือคลิปต้นฉบับ เพื่อลดความเสี่ยงด้านลิขสิทธิ์
- ข้อสังเกตจากการถอดเอกสาร: ระบบโตแบบต่อเติม จึงมีความซ้ำซ้อน (ดู 04-architecture.md ข้อ 7 และประเด็นที่ 10)

## 7. คำศัพท์

ชื่อในตารางนี้เป็นชื่อเดียวที่ใช้ทั้งชุดเอกสาร

| คำ | ความหมาย |
|---|---|
| คลิป | วิดีโอหนึ่งไฟล์ในคลัง มีแคปชัน และสถานะ ชนิดมี "เร็ว" กับ "เรื่อง" |
| โปรเจกต์เรื่อง | เรื่องหนึ่งเรื่องที่แตกเป็นช็อต มีตัวละคร สถานที่ ของประกอบ และเทมเพลต |
| ช็อต | หนึ่งภาพหรือหนึ่งคลิปสั้นในโปรเจกต์เรื่อง มีคำบรรยาย พรอมต์ รูป |
| คลังตัวละคร | รายการตัวละคร สถานที่ และของประกอบของโปรเจกต์ ใช้ใส่ซ้ำในพรอมต์ทุกช็อตเพื่อให้หน้าตาคงที่ |
| เทมเพลต B | รูปแบบคลิปสปอยล์: ป้ายตอน มิเตอร์ระดับสปอยล์ แถบบรรยาย กล่องข้อความ คำเสียง การ์ดปกและจบ |
| ซีรีส์ | เรื่องที่ผลิตเป็นตอน ๆ ต่อเนื่อง ตั้งค่าไว้ครั้งเดียว |
| ตอนซีรีส์ | หนึ่งตอนของซีรีส์ เช่น EP.1 เก็บเป็น "งานผลิตตอน" |
| บทนิยาย | หนึ่งบทของนิยายต้นฉบับ เช่น ตอนที่ 1 ของคัมภีร์วิถีเซียน ห้ามเรียกว่า "ตอน" เฉย ๆ |
| งานผลิตตอน | แถวติดตามการผลิตหนึ่งตอนซีรีส์ ตั้งแต่ค้นเนื้อเรื่องจนลงครบ |
| การลง | บันทึกการโพสต์หนึ่งตอนลงหนึ่งช่องทาง |
| ช่องทาง | Facebook หรือ YouTube |
| เพจ / ช่อง | ชื่อเพจ Facebook หรือช่อง YouTube ที่จะลง |
| ป้ายเนื้อหา AI | ตัวเลือกบน Facebook และ YouTube ที่ระบุว่าเนื้อหาสร้างหรือดัดแปลงด้วย AI |
| ผู้สร้างรูป | เว็บที่ใช้วาดรูปช็อต: Gemini, ChatGPT, Google Flow, Meta AI, Seedance |
| พรอมต์ | ข้อความสั่งให้ผู้สร้างรูปหรือวิดีโอ |
