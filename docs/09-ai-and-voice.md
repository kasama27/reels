# AI เสียงบรรยาย และส่วนเสริม Chrome (AI, Voice, Companion)

รวมการเชื่อมต่อที่ระบบทำแล้วและใช้อยู่ ได้แก่ Claude สำหรับเขียนเนื้อหา บริการเสียงบรรยาย และส่วนเสริม Chrome ข้อจำกัดและราคาของบริการภายนอกเปลี่ยนได้ ตรวจค่าปัจจุบันก่อนตัดสินใจ

## 1. สิ่งที่ต้องเตรียม

| สิ่งที่ต้องมี | ใช้ทำอะไร | หมายเหตุ |
|---|---|---|
| Claude Code ที่ล็อกอินไว้ (ค่าเริ่มต้นถ้าไม่มีคีย์) หรือคีย์ Claude API | เขียนสคริปต์ แคปชัน สตอรีบอร์ด คำบรรยาย ค้นความรู้ อ่านรูป | เลือกในหน้าตั้งค่า โหมดบัญชีใช้โควตาของแผนเจ้าของ |
| ผู้ให้บริการเสียง: Windows (ไม่ต้องใช้คีย์), Google Cloud (คีย์), Gemini (คีย์) | เสียงบรรยายภาษาไทย | เลือกในหน้าตั้งค่า |
| ส่วนเสริม Chrome ที่ติดตั้งแบบนักพัฒนา | ส่งรูปเข้าช็อตจากหน้าผู้สร้างรูป | ไม่บังคับ |

## 2. Claude

- โหมดบัญชี: เซิร์ฟเวอร์เรียกโปรแกรม `claude` แบบไม่มีหน้าจอ ทำงานในโฟลเดอร์ว่าง ปิดเครื่องมือทั้งหมด ตอบเป็นข้อความเท่านั้น ยกเลิกได้เมื่อหน้าเว็บตัดการเชื่อมต่อ
- โหมดคีย์: เรียก API ตรง เร็วกว่า คิดเงินตามการใช้จริง
- ใช้ใน: สคริปต์คลิป ความรู้จากคีย์เวิร์ด อ่านรูป แคปชัน พรอมต์ ร่างคลังตัวละคร แบ่งช็อต คำบรรยาย สตอรีบอร์ดตามหัวข้อ (รวมแท็ก Caption SFX Meter ของเทมเพลต B) เรื่องล้อเลียน เรียบเรียงข่าว เลือกสินค้า
- ข้อมูลที่ส่งไป: ข้อความที่เจ้าของใส่ ข้อความจากข่าวที่เลือก และรูปที่เจ้าของส่งให้อ่าน

## 3. เสียงบรรยาย

| ผู้ให้บริการ | ต้องมี | หมายเหตุ |
|---|---|---|
| Windows | เสียงไทยของ Windows | ฟรี ออฟไลน์ เรียกผ่านสคริปต์ PowerShell |
| Google Cloud TTS | คีย์ Google | ตั้งเสียงได้ |
| Gemini | คีย์ Gemini | ใช้ในตอนทดลอง EP.1 |

- ทุกทางสร้างไฟล์ WAV แคชตามข้อความ ข้อความเดิมไม่สร้างซ้ำ
- ในคลิปรวมเรื่อง ความยาวช็อตเท่าความยาวเสียงบวกช่วงนำและท้าย
- เทมเพลต B มิกซ์ท้ายสายให้เสียงแน่นสม่ำเสมอ (เป้าดู 03-flows.md ตาราง "ค่าที่ตั้งได้ในระบบ") ค่าที่วัดจากคลิปทดลอง EP.1: ระดับกลาง −14.1 dBFS ช่วงดังสุด 5% −9.7 พีค −2.1 ซึ่ง **ดังกว่าคลิปตัวอย่าง** เมื่อรวมเพลง ยังไม่มีการฟังด้วยหูจริง (ประเด็นที่ 16)

## 4. ส่วนเสริม Chrome (Arn Reels Companion — ปัจจุบัน v0.5.0)

- **v0.5.0 (30 ต.ค. 2026):** แผง "🛍 Arn Reels · หาสินค้า" บน affiliate.shopee.co.th และโหมด "🛍 คลิปสินค้า" บน meta.ai (วาง prompt + แนบรูป ส่งวิดีโอกลับ) ทดสอบกับหน้าจำลองเท่านั้น รายละเอียดใน 14-product-clips.md
- เสียงพากย์: สไตล์เสียง (`story.NARR_TONES`) ใช้ร่วมกับคลิปเร็วแล้ว ส่งเป็น `tone` ตอนขอเสียงจาก `/api/tts`

- ทำอะไร: วางพรอมต์ของช็อตถัดไปลงช่องพิมพ์ของ Meta AI หรือ Google Flow (ไม่กดส่งให้) และเมื่อมีรูปหรือวิดีโอใหม่ ให้เจ้าของกดส่งเข้าช็อต
- หน้าที่รองรับ: meta.ai, flow.google.com และ gemini.google.com (รุ่น 0.3.0 ทดสอบกับหน้าจริงแล้ว 28 ต.ค. 2026: วางพรอมต์ ส่งรูปเข้าช็อตด้วยการกดปุ่มในแผง ได้ไฟล์ JPEG 572 × 1024 ตรงพรอมต์ ส่วนโหมดส่งอัตโนมัติ และให้ผู้ช่วย AI ขับหน้า Gemini เอง ยังไม่ได้ทดสอบ) ไม่รองรับ ChatGPT
- รุ่น 0.3.0 เพิ่ม: ตัดคำบรรยายไทยออกจากพรอมต์ตอนวางลง Gemini, ตัวเลือก "ส่งรูปเข้าช็อตให้เอง" (ปิดไว้ก่อน รอให้รูปนิ่ง 8 วินาที), สำรองวิธีดึงรูปผ่านผืนผ้าใบเมื่อหน้าเว็บบล็อกการอ่านไฟล์, และคำสั่งผ่านเหตุการณ์ DOM (arn-fill, arn-reload) กับสถานะที่อ่านได้ ให้ผู้ช่วย AI ใช้
- การเชื่อมกับแอป: ผ่านเส้นทาง `/ext/` (06-api-spec.md ข้อ 8) ต้องมีรหัสจับคู่ซึ่งเจ้าของคัดลอกจากหน้าตั้งค่าไปใส่ในตัวเลือกของส่วนเสริม ตรวจ Host และ Origin ด้วย
- ข้อสังเกต: นี่คือทางส่งไฟล์ตรงเข้าแอปที่ปลอดภัย ไม่ต้องเปิดช่องใหม่ในเซิร์ฟเวอร์ (ประเด็นที่ 11 ตัดสินใจแล้ว) ข้อควรรู้: ส่วนเสริมอยู่ใน Chrome ของเจ้าของ ผู้ช่วย AI ต้องทำงานใน Chrome ตัวนี้ (ผ่านส่วนเสริมควบคุมเบราว์เซอร์) แผงเบราว์เซอร์ในแอปไม่มีส่วนเสริมนี้ (ประเด็นที่ 12) ข้อกังวล: สคริปต์ของหน้าเว็บภายนอกส่งเหตุการณ์ arn-fill ได้เช่นกัน ผลจำกัดแค่การวางพรอมต์ในช่องและส่งรูปที่เพิ่งสร้างเข้าช็อตของเรา

## 5. ข้อจำกัดที่ต้องรู้

| เรื่อง | ข้อจำกัด | ผลต่อระบบ |
|---|---|---|
| โควตา Claude ในโหมดบัญชี | ใช้โควตาแผนของเจ้าของ งานรายวันกินโควตาด้วย | ตรวจก่อนตั้งงานรายวัน |
| Gemini TTS | ใช้รุ่นตัวอย่าง (preview) ที่ตั้งค่าไว้ รุ่นหรือราคาเปลี่ยนได้ | ตรวจค่าปัจจุบัน |
| เสียงภาษาไทย | การออกเสียงชื่อเฉพาะอาจผิด | ต้องฟังตัวอย่างก่อนปล่อย ยังไม่ได้ฟัง |
